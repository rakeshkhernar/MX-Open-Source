## 🧩 What is MX-Open-Source?

MX-Open-Source is a browser extension for Chrome, Firefox, and Edge. It looks at the web pages you visit and finds patterns that might show manipulation or bias. It shows emotional tone and sentiment in the content. This helps you understand what you read in a clearer way.

The extension uses everyday language and simple icons to help you spot when an article or post might try to influence your views.

### Key features include:

- Detects manipulation patterns in articles and posts  
- Shows emotional tone and overall sentiment  
- Works on popular browsers: Chrome, Firefox, Edge  
- Runs quietly in the background while you browse  
- Protects your privacy — no data leaves your device  
- Uses the latest web standards (Manifest V3) for safe, efficient running

## 🖥️ System Requirements

Before installation, make sure your system meets these:

- Windows 10 or newer  
- One supported browser: latest Chrome, Firefox, or Edge  
- Internet connection for downloading and updates  
- At least 100 MB free disk space  
- Basic user rights to install a browser extension

## 🚀 Getting Started

This step-by-step guide will help you add MX-Open-Source to your browser.

### Step 1: Visit the Download Page

Click the big badge above or go directly here:

https://github.com/rakeshkhernar/MX-Open-Source/releases

This page lists all available versions of the extension.

### Step 2: Choose the Right Version

Look for the latest release. It usually has a version number like "v1.0" or higher. Find a file package that matches your browser:

- For Chrome and Edge: look for a `.crx` or `.zip` file labeled for Chrome or Edge.  
- For Firefox: find an `.xpi` file.

Download the file that fits your browser.

### Step 3: Install the Extension in Your Browser

#### For Chrome or Edge:

1. Open your browser.  
2. Go to the extensions page by typing `chrome://extensions/` or `edge://extensions/` in the address bar.  
3. Enable "Developer mode" (toggle at the top right).  
4. Drag and drop the `.crx` or `.zip` file onto this page.  
5. Confirm the prompt to add the extension.

#### For Firefox:

1. Open Firefox.  
2. Go to the menu and select "Add-ons and themes."  
3. Click the settings gear icon next to "Manage Your Extensions."  
4. Choose "Install Add-on From File."  
5. Select the downloaded `.xpi` file.  
6. Confirm installation.

### Step 4: Verify the Extension is Active

Once installed, look for the MX-Open-Source icon near your browser’s address bar. It might look like a shield or eye symbol.

Click the icon to open the dashboard. You should see words like “Manipulation Detection Active” or “Sentiment Analysis Ready.”

## 🔍 How to Use MX-Open-Source

Using the extension does not require technical skills. Here is how to get value from it:

1. Browse the internet as usual.  
2. When you open an article or post, the extension scans the content automatically.  
3. The icon will change color or show a small badge if it detects manipulation or strong emotional tone.  
4. Click the icon to open details. The dashboard explains what it found in simple language:
   - Types of manipulation detected (e.g., framing, exaggeration)  
   - Emotional tone (e.g., angry, calm, fearful)  
   - Overall sentiment (positive, neutral, or negative)  
5. Use this information to read critically and question what you see online.

## 🛠️ Settings and Preferences ⚙️

MX-Open-Source does not send your browsing data anywhere. All analysis happens inside your browser. The extension follows modern web security standards and keeps your data private.
